## 1. 里程碑 DoD 验收标准

### M1 —— 核心链路打通（目标：转账场景端到端）

| # | 验收项 | 验证方式 |
|---|---|---|
| 1 | bank-core 启动，9 张表建齐，种子数据可查询 | `GET /api/accounts` 返回张三余额 ¥52,300；通讯录含 2 个李磊 |
| 2 | 写操作幂等 | 同一 `Idempotency-Key` 重复 POST /api/transfers → 返回首次结果，余额只扣一次 |
| 3 | LangGraph 图骨架可运行 | intent→planner→executor→responder 全链路打印 trace |
| 4 | 权限引擎静态+动态定级 | 单元测试：转账≤1000 当日累计→黄；>1000→红；陌生收款人升级 |
| 5 | 黄色确认链路 | "给赵敏转 200"→ 确认卡片 → 确认后到账；拒绝/超时→不执行 |
| 6 | 红色 MFA 链路 | "给李磊转 5000"→ 消歧 → 确认 → 模拟短信码 → 通过执行；错 3 次锁定 |

| 9 | Web 极简聊天页 | WebSocket 收发消息、渲染确认卡片与 MFA 弹窗（样式可粗糙） |

## 3. 部署与运行细节

### 3.1 Dockerfile 要点

| 镜像 | 基础镜像 | 关键步骤 |
|---|---|---|
| bank-core | python:3.12-slim | 安装 requirements → 复制 app/ → 启动时自动建表+种子（`seed.py` 幂等：有库跳过）→ `uvicorn app.main:app --port 8100` |
| agent-service | python:3.12-slim | 同上 + 启动期校验 `LLM_API_KEY` 存在（缺失则进入"LLM 降级模式"仍可演示查询）→ `--port 8200` |
| web-app | node:20-alpine → nginx:alpine | `npm ci && npm run build` → dist 复制到 nginx；nginx.conf 配置 `/ws` 与 `/api` 反代到 agent-service:8200 |

### 3.2 本地开发脚本（`scripts/dev.ps1`）

```
1. 启动 bank-core:   uvicorn app.main:app --port 8100 --reload  (cwd=bank-core)
2. 启动 agent:       uvicorn app.main:app --port 8200 --reload  (cwd=agent-service)
3. 启动前端:         npm run dev                                (cwd=web-app)
三个进程独立 PowerShell 窗口，Ctrl+C 可单独重启。
```

### 3.3 数据重置脚本（`scripts/reset_demo.ps1`，演示前必跑）

```
1. 停 bank-core → 删 bank.db → 重启（自动重建+种子）
2. 清 agent-service 的 audit/pending/mfa/breaker 表与 checkpoints
3. 输出"演示数据已就绪"检查清单（余额/联系人/订阅数）
```

### 3.4 回归脚本（`scripts/regression.ps1`）

按序执行 6 场景标准对话（HTTP/WS 脚本驱动），断言每步响应关键字；全部通过输出绿色报告——演示前最后一道保险。
